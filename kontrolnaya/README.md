Сделала все 4 маршрута:
GET /quizzes - список тестов, там же фильтр по minQuestions и считается среднее (это было доп задание).
GET /quizzes/details?id=1 - показывает один тест.
POST /quizzes/create - создает тест, статус всегда ставится open.

Как запустить: в терминале написать dotnet run и открыть в браузере http://localhost:8080/quizzes
