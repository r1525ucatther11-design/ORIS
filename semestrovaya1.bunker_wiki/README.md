Вики Бункер - сайт с карточками игры, правилами и админкой для редактирования. 

Особенность дизайна: Для каждой категории карточек (профессии, биология, катастрофы и т.д.) сделал свой уникальный фон-картинку, чтобы карточки выглядели стильно и их было легко различать визуально.

Как запустить:

- В PostgreSQL создаете базу данных retail.
- Выполнить в ней скрипт из файла schema.sql, чтобы он создал таблицы и добавил данные.
- Открыть файл DatabaseContext.cs и в строке подключения, где "Password=" вписать свой пароль от базы.
- В терминале выполнить: dotnet run
- Открыть в браузере http://localhost:8080/
- Перейти на Админку на самом сайте или же ввести: http://localhost:8080/admin 
(Если не получилось запустить, в DatabaseContext.cs заменить "host=localhost" на "host=host.docker.internal.", об этом расписано чуточку ниже)

- Запросит логин и пароль, введите:
Логин: admin
Пароль: admin123

- Про Docker:
Тут есть один нюанс: внутри контейнера localhost не видит базу данных на компьютере. Долго копалась, решение нашла только такое: перед сборкой нужно в DatabaseContext.cs заменить localhost на host.docker.internal. Потом можно вернуть обратно, когда запускаешь локально.

- В DatabaseContext.cs заменить host=localhost на host=host.docker.internal.
Ввести команды:
docker build -t bunker-wiki .
docker run -d -p 127.0.0.1:8080:8080 bunker-wiki
Открыть http://localhost:8080/cards

- Важно: После проверки Docker (или если вы запускаете проект локально через dotnet run), нужно вернуть host=localhost в DatabaseContext.cs. Иначе тесты и локальный запуск не смогут подключиться к базе. (на всякий случай)
